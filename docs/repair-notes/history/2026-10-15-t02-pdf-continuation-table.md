15 October 2026 — T02 continuation PDF source tables (partial)
The delivery/source PDF reader previously forgot headers at each physical-page boundary, silently dropping valid continuation-page register rows. Adjacent native/OCR pages may now carry a verified tabular header when the previous page ended with source-identifiable rows. Continuations must preserve source record identity and each actual page/line. Unread/non-adjacent pages never carry header authority. Tests use immutable SHA-pinned original PDF input and assert true multi-page population and source locators. Remaining T02 file types and blind acceptance still open. No deployment.
