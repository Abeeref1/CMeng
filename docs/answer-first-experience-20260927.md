# Answer-first project experience — 27 September 2026

## Problem traced

The live UPTOWN-100 Management Brief led with a quantities finding despite having usable programme dates. The project showed 28 page-oriented actions. `positionVerdict` promoted the first evidence finding into a generic page headline; the shared renderer placed verdict and basis administration before most analytical results. Only a small page allow-list led with results. Project actions grouped consequences by page and sent users to another page rather than showing the difference.

## Shared correction

- Analytical results lead by default, including leadership views. Review details follow. A genuinely unread register still withholds its dependent values.
- Completion Forecast, Management Brief, Master Dashboard, Command Center and project Ask consume the same completion-position projection. Submitted finish, calendar recalculation and contractual finish remain separate. Missing contract or quantity inputs do not remove a usable programme forecast.
- The comparison preserves exact elapsed-day differences, states calculation assumptions and includes named activity date differences in one inline disclosure. It does not turn reconciliation into proven delay causation or entitlement.
- Project review groups findings by the underlying information/decision subject, retains every original finding and affected page, and separates missing optional domains from decisions. It opens on the current page. Source adoption, document replacement and population decisions remain explicit.
- Successful uploads return to the dashboard and open the consolidated review only when a document decision remains. Project switching retains each upload's captured ownership. A refresh failure after saving does not report the document upload as failed.
- Ask answers schedule-delay questions with actual activity lists, float pressure, the available finish comparison and confirmed linked blockers. Unrelated missing registers are not automatically added. Source float remains distinct from an independently established critical path; unavailable data is not zero, and Top N selections retain their full matching populations.

## Additional defects exposed by the real programme

The supplied 58.7 MB, 25,630-activity XER was re-ingested into an isolated local project. Large resource-anchor arrays overflowed JavaScript argument limits in resource curves. Unbounded numeric spreads were replaced with reductions/iteration in the affected schedule/resource/quantity calculations, preserving arithmetic. A 70,000-assignment check verifies exact aggregate hours and curve endpoints.

Native XER WBS labels followed by numeric IDs were also being interpreted as prose KPI assertions. Native-table parsing now owns those facts. Historical extraction receipts are retained, while those false prose matches are excluded from report-assertion comparisons. Genuine narrative report assertions remain checked.

## Limits
